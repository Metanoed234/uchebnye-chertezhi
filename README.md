## Как открыть

Скачайте нужный `.dwg` и откройте в AutoCAD. Все листы оформлены на формате A4 (297×210 мм, альбомная ориентация); граница листа — на слое «Формат_A4».

Печать уже настроена: принтер «DWG To PDF», лист ISO A4, масштаб 1:1. Для бумажной печати выберите свой принтер и оставьте масштаб 1:1.

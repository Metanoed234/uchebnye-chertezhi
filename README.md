# Учебные чертежи

Листы с условными знаками по курсу «Землеустройство и кадастры», выполненные в AutoCAD.

| Лист | Название | Файл |
|---|---|---|
| №1 | Сетка квадратов | [Setka_kvadratov_1.dwg](Setka_kvadratov_1.dwg) |
| №6 | Линейные знаки | [Lineynye_znaki_6.dwg](Lineynye_znaki_6.dwg) |
| №8 | Угодья и растительность | [Ugodya_i_rastitelnost_8.dwg](Ugodya_i_rastitelnost_8.dwg) |

## Как открыть

Скачайте нужный `.dwg` и откройте в AutoCAD. Формат листа — A4: №6 и №8 — альбомная ориентация, рамка 260×170 мм; №1 — рамка 180×120 мм.

Перед печатью выберите свой принтер в настройках печати.

# Учебные чертежи

Листы с условными знаками по курсу «Землеустройство и кадастры», выполненные в AutoCAD.

| Лист | Название | Файл |
|---|---|---|
| №1 | Виды сеток и масштабов | [Vidy_setok_i_masshtabov_1.dwg](Vidy_setok_i_masshtabov_1.dwg) |
| №2 | Сетка квадратов | [Setka_kvadratov_2.dwg](Setka_kvadratov_2.dwg) |
| №3 | Типы линий | [Tipy_liniy_3.dwg](Tipy_liniy_3.dwg) |
| №4 | Стандартный шрифт | [Standartnyy_shrift_4.dwg](Standartnyy_shrift_4.dwg) |
| №6 | Линейные знаки | [Lineynye_znaki_6.dwg](Lineynye_znaki_6.dwg) |
| №8 | Угодья и растительность | [Ugodya_i_rastitelnost_8.dwg](Ugodya_i_rastitelnost_8.dwg) |

## Как открыть

Скачайте нужный `.dwg` и откройте в AutoCAD. Формат листа — A4: №6 и №8 — альбомная ориентация, рамка 260×170 мм; №1 — рамка 240×160 мм; №2 — рамка 180×120 мм; №3 — рамка 180×130 мм; №4 — рамка 250×172 мм.

Перед печатью выберите свой принтер в настройках печати.
